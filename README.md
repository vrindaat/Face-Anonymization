# Feature Retention in Face Anonymization

This repository contains the code for the Project on Feature Retention in Face Anonymization. The project is based on the "Face Anon Made Simple" GitHub repository.

## Files

### Jupyter Notebooks

* **`demo.ipynb`**: This notebook provides a demonstration of the face anonymization pipeline.
* **`comparison_FaceIds.ipynb`**: This notebook compares the cosine similarity of Face IDs. It computes an average cosine similarity of 0.6083.
* **`comparison_saving_outputs.ipynb`**: This notebook is used for saving the outputs of the face anonymization process for comparison.
* **`fine-tuning_validation_embeddingloss.ipynb`**: This notebook is for fine-tuning the model with validation and embedding loss.
* **`fine-tuning_working.ipynb`**: This notebook contains a working example of the fine-tuning process.
* **`gender_example.ipynb`**: This notebook provides an example of gender classification with an accuracy of over 84%.
* **`loss_plot.ipynb`**: This notebook is used to plot the training and validation loss.

### Python Scripts

* **`pipeline_referencenet_final.py`**: This script contains the final version of the StableDiffusionReferenceNetPipeline.
